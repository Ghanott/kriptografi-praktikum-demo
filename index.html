Arsitektur Algoritma & Skrip Praktik Lapangan

Struktur Feistel 16-Ronde (DES)

Feistel Network
1. Initial Permutation (IP)

64-bit data dipermutasi bitnya via tabel IP, kemudian dibagi dua bagian: $L_0$ (32-bit) dan $R_0$ (32-bit).

2. Inti Ronde Feistel
$L_i = R_{i-1}$
$R_i = L_{i-1} \oplus f(R_{i-1}, K_i)$

Fungsi $f(R, K)$ melibatkan: Ekspansi $E$ (32→48 bit), XOR subkunci $K_i$, 8 S-box (S1..S8 reduksi 48→32 bit), dan Permutasi $P$.

3. Key Schedule DES

Kunci 64-bit → PC-1 (56-bit) → $C_0, D_0$ (28-bit) → Left Shift → PC-2 menghasilkan 16 subkunci 48-bit ($K_1 \dots K_{16}$).

Struktur SPN State Matrix $4 \times 4$ (AES)

SPN Network
State Matrix 4×4 Byte

Skrip Praktik Eksekusi (Python & OpenSSL CLI)

Implementation Code
Python 3 (Library cryptography)
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
import os

# Enkripsi AES-256-GCM (Standar Modern)
key = os.urandom(32)  # 256-bit key
iv = os.urandom(12)   # 96-bit nonce
encryptor = Cipher(algorithms.AES(key), modes.GCM(iv)).encryptor()
ciphertext = encryptor.update(b"Pesan Rahasia Siber") + encryptor.finalize()
tag = encryptor.tag

print("Ciphertext:", ciphertext.hex())
print("Auth Tag:", tag.hex())
OpenSSL CLI Commands
# 1. Enkripsi AES-256-CBC dengan PBKDF2
openssl enc -aes-256-cbc -salt -pbkdf2 \
  -in data.txt -out data.enc -k KunciRahasiaKu

# 2. Dekripsi AES-256-CBC
openssl enc -d -aes-256-cbc -pbkdf2 \
  -in data.enc -out data_pulih.txt -k KunciRahasiaKu

# 3. Enkripsi DES (Legacy - Hanya untuk uji lab)
openssl enc -des-cbc -in data.txt -out data.des -k SandiLama
