Praktik Enkripsi & Dekripsi Data: Algoritma DES

Pengujian langsung algoritma Data Encryption Standard (DES) berbasis jaringan Feistel 16-ronde dengan ukuran blok 64-bit.

Informasi Teknis Algoritma DES

Feistel Network
Ukuran Blok 64-bit (8 Byte) Dibagi menjadi L (32-bit) dan R (32-bit)
Panjang Kunci Efektif 56-bit Dari total 64-bit (8-bit digunakan sebagai paritas)
Jumlah Ronde 16 Ronde Subkunci ronde: 48-bit per ronde (PC-1 & PC-2)
Status Keamanan NIST Dipensiunkan (2005) Rentan brute-force karena ruang kunci hanya $2^{56}$

Mekanisme Feistel: Setelah Permutasi Awal (IP), blok dibagi menjadi $L_0$ dan $R_0$. Di setiap ronde dihitung $L_i = R_{i-1}$ dan $R_i = L_{i-1} \oplus f(R_{i-1}, K_i)$. Fungsi $f$ mencakup ekspansi $E$ (32→48 bit), XOR subkunci $K_i$, substitusi 8 kotak non-linear (S-Box S1..S8), dan permutasi $P$. Dekripsi menggunakan struktur yang identik dengan membalik urutan subkunci ($K_{16}$ ke $K_1$).

Parameter Pengujian DES

32 karakter
Kunci dinormalisasi menjadi tepat 8 byte (56 bit efektif + 8 bit paritas).
Digunakan pada mode CBC untuk mengacak blok 64-bit pertama.

Skrip Implementasi Python: Algoritma DES

Python 3 • Cryptography Library

Implementasi enkripsi dan dekripsi DES mode CBC dengan padding PKCS#7 menggunakan library standar industri cryptography.

des_cipher.py Python 3 
import os
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
from cryptography.hazmat.primitives import padding

def des_encrypt_cbc(plaintext: str, key_8bytes: bytes) -> tuple[bytes, bytes]:
    """Enkripsi teks menggunakan DES mode CBC dengan PKCS7 padding."""
    # DES membutuhkan Initialization Vector (IV) sepanjang 8 byte (64 bit)
    iv = os.urandom(8)

    # Padding data ke kelipatan blok DES (8 byte / 64 bit)
    padder = padding.PKCS7(64).padder()
    padded_data = padder.update(plaintext.encode('utf-8')) + padder.finalize()

    # Inisialisasi Cipher DES (TripleDES 3-key identik untuk kompatibilitas DES)
    # Catatan: DES murni memakai kunci 8 byte (56 bit efektif)
    cipher = Cipher(algorithms.TripleDES(key_8bytes * 3), modes.CBC(iv))
    encryptor = cipher.encryptor()
    ciphertext = encryptor.update(padded_data) + encryptor.finalize()

    return iv, ciphertext

def des_decrypt_cbc(iv: bytes, ciphertext: bytes, key_8bytes: bytes) -> str:
    """Dekripsi ciphertext DES mode CBC dan unpadding PKCS7."""
    cipher = Cipher(algorithms.TripleDES(key_8bytes * 3), modes.CBC(iv))
    decryptor = cipher.decryptor()
    padded_plain = decryptor.update(ciphertext) + decryptor.finalize()

    unpadder = padding.PKCS7(64).unpadder()
    plaintext_bytes = unpadder.update(padded_plain) + unpadder.finalize()
    return plaintext_bytes.decode('utf-8')

# --- Contoh Pengujian ---
if __name__ == "__main__":
    kunci_rahasia = b"KunciDES"  # Tepat 8 byte
    pesan = "Sistem Keamanan Siber Pertemuan 7"

    iv, cipher = des_encrypt_cbc(pesan, kunci_rahasia)
    print(f"[DES] Ciphertext (Hex): {cipher.hex().upper()}")
    print(f"[DES] IV (Hex)        : {iv.hex().upper()}")

    pulih = des_decrypt_cbc(iv, cipher, kunci_rahasia)
    print(f"[DES] Pulih (Plain)   : {pulih}")
    assert pesan == pulih, "Validasi gagal!"
    print("[DES] Status           : Dekripsi Berhasil & Identik.")

Praktik Enkripsi & Dekripsi Data: Algoritma AES

Pengujian langsung Advanced Encryption Standard (AES / Rijndael, FIPS 197) dengan arsitektur Substitution-Permutation Network (SPN).

Informasi Teknis Algoritma AES

SPN Network (FIPS 197)
Ukuran Blok 128-bit (16 Byte) Direpresentasikan sebagai State Matrix $4 \times 4$
Pilihan Panjang Kunci 128, 192, atau 256-bit AES-128 (10 ronde), AES-192 (12), AES-256 (14)
Akselerasi CPU Didukung Hardware Instruksi Intel/AMD AES-NI & ARM Cryptography
Status Keamanan NIST Standar Aktif Belum ada serangan analitis praktis hingga saat ini

Mekanisme SPN: Berbeda dengan Feistel, seluruh blok 128-bit diproses serentak di tiap ronde melalui 4 transformasi matematis: SubBytes (substitusi non-linear S-box GF($2^8$)), ShiftRows (permutasi siklis per baris), MixColumns (perkalian matriks linear per kolom untuk difusi), dan AddRoundKey (XOR dengan subkunci ronde). Ronde terakhir mengecualikan MixColumns.

Parameter Pengujian AES

34 karakter
Panjang kunci otomatis disesuaikan (16 byte untuk 128-bit, 32 byte untuk 256-bit).
12 byte untuk mode GCM, 16 byte untuk mode CBC/CTR.

Skrip Implementasi Python: Algoritma AES (GCM & CBC)

Python 3 • Cryptography Library

Implementasi enkripsi modern AES-256-GCM (AEAD yang menjamin kerahasiaan + autentikasi keaslian data) serta mode tradisional AES-CBC.

aes_cipher.py Python 3 
import os
from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes

# =====================================================================
# 1. METODE UTAMA: AES-256-GCM (Authenticated Encryption with Associated Data)
# =====================================================================
def aes_gcm_encrypt(plaintext: str, key_32bytes: bytes) -> tuple[bytes, bytes, bytes]:
    """
    Enkripsi AES-256 mode GCM.
    Menghasilkan: (nonce 12-byte, ciphertext, authentication tag 16-byte).
    """
    # Standar rekomendasi NIST untuk nonce GCM adalah 96-bit (12 byte)
    nonce = os.urandom(12)

    encryptor = Cipher(
        algorithms.AES(key_32bytes),
        modes.GCM(nonce)
    ).encryptor()

    ciphertext = encryptor.update(plaintext.encode('utf-8')) + encryptor.finalize()
    tag = encryptor.tag  # MAC integrity tag (16 byte)

    return nonce, ciphertext, tag

def aes_gcm_decrypt(nonce: bytes, ciphertext: bytes, tag: bytes, key_32bytes: bytes) -> str:
    """
    Dekripsi AES-256 mode GCM.
    Memverifikasi keaslian ciphertext sebelum didekripsi (Anti-Tampering).
    """
    decryptor = Cipher(
        algorithms.AES(key_32bytes),
        modes.GCM(nonce, tag)
    ).decryptor()

    # Akan melempar InvalidTag exception jika ciphertext diubah 1 bit sekalipun
    decrypted_bytes = decryptor.update(ciphertext) + decryptor.finalize()
    return decrypted_bytes.decode('utf-8')

# --- Contoh Pengujian ---
if __name__ == "__main__":
    kunci_aes = os.urandom(32)  # Kunci 256-bit acak
    pesan_asli = "Kriptografi Simetris Pertemuan 7"

    nonce, ciphertext, tag = aes_gcm_encrypt(pesan_asli, kunci_aes)
    print(f"[AES-GCM] Nonce      : {nonce.hex().upper()}")
    print(f"[AES-GCM] Ciphertext : {ciphertext.hex().upper()}")
    print(f"[AES-GCM] Auth Tag   : {tag.hex().upper()}")

    pesan_pulih = aes_gcm_decrypt(nonce, ciphertext, tag, kunci_aes)
    print(f"[AES-GCM] Pulih      : {pesan_pulih}")
    assert pesan_asli == pesan_pulih, "Integritas data tidak cocok!"
    print("[AES-GCM] Status     : Sukses Terverifikasi (Kerahasiaan + Keaslian Data).")
